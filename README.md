# Python Calculator with CI/CD

Простой учебный проект на Python, демонстрирующий настройку автоматического тестирования (CI) с помощью GitHub Actions и библиотеки `pytest`.

## 🚀 Описание

Проект содержит базовый модуль калькулятора с функциями сложения и деления, а также набор автотестов, которые проверяют корректность работы логики (включая обработку ошибок вроде деления на ноль).

## 🛠️ Локальный запуск

Чтобы запустить проект и тесты на своем компьютере, выполните следующие шаги:

### 1. Клонируйте репозиторий
```bash
git clone https://github.com
cd имя_репозитория
```

### 2. Создайте и активируйте виртуальное окружение
```bash
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для macOS/Linux:
source .venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Запустите автотесты
```bash
export PYTHONPATH=./src
pytest tests/
```
*(Для Windows в командной строке вместо `export` используйте `set PYTHONPATH=./src`)*

## 🔄 Непрерывная интеграция (CI)

При каждом `git push` в ветки `main` или `master`, а также при создании Pull Request, автоматически запускается сценарий GitHub Actions (`.github/workflows/tests.yml`). Он выполняет:
1. Развертывание окружения на базе Ubuntu.
2. Установку Python 3.11.
3. Установку зависимостей из `requirements.txt`.
4. Запуск тестов через `pytest`.
